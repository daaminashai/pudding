# knowledge/

Drop the documents the drafter should answer from in this folder, as `.md` or
`.txt` files (subfolders are fine): the FAQ, the organizer doc, policies,
event details. Export Google Docs with File → Download → Markdown or Plain text.

- Every file here is sent to the model with every draft, so keep it to things
  that are true and current. Delete outdated docs rather than leaving them in.
- Files starting with `_` (like this one and `_style.md`) are never sent.
- Past replies don't go here: they're pulled from the inbox automatically.
- Text inside `<!-- -->` comments is stripped before sending.
